# TrueNAS Proxy Add-on

Open your local TrueNAS SCALE web UI from the Home Assistant sidebar.

## Installing

In Home Assistant, navigate to _Settings_ > _Add-ons_ > _Add-on Store_ > _..._ > _Repositories_ and add the URL of this repository.

## Add-ons provided by this repository
- [TrueNAS Proxy](truenas_proxy/README.md)
